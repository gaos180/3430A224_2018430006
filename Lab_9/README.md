# Laboratorio 9

> El laboratorio número 9 trata acerca de hash y colisiones. Está escrito en C++
> por lo que se debe de trabajar con C++

> [!TIP]
> Para la compilación se debe de usar la siguiente línea de comando
> g++ -o lab9 lab_9.cpp 

> [!IMPORTANT]  
> Se debe de escoger el tamaño de la matriz y como solucionar las colisiones con {L|C|D} Lineal
> Cuadrática o DobleHash.

> [!WARNING]  
> Esta definido que será aleatorio el número dentro de la matriz, si se desea poner otro, hay que
> cambiar el código.
