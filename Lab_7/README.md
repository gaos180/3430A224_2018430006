# Laboratorio 7 - POA

>[!WARNING]
> Este programa está enfocado para Linux que contenga Graphviz y EOG
> Usando el siguiente en caso de:
> sudo apt install graphviz eog


Este laboratorio es de el algoritmo PRIM, que usando una matriz de adyascencia como el de djikstra se realiza
la búsqueda del camino abarcador de costo mínimo, está basado en la presentación que en su momento no había visto
el algoritmo de PRIM, la cual es correspondiente a la clase 5 de grafos.

Se realiza según la adyascencia la vinculación de los nodos, para poder encontrar el coste mínimo de abarcarlos
